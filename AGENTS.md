# Инструкции для ИИ-агента

Эти правила действуют на весь репозиторий, когда агент пишет или правит код.

## Комментарии

Никогда не оставляй комментарии в коде. Ни в новых файлах, ни в правках существующих. Имена переменных и функций должны объяснять код сами.

## Как писать код

Пиши код так, чтобы его понял джуниор. Простые имена, прямой порядок действий, без хитрых сокращений.

```ts
const closeTimer = setTimeout(() => {
  dispatch(closeModal());
}, 7000);
```

Так делать не нужно:

```ts
useEffect(() => void (open && setTimeout(() => dispatch(closeModal()), 7e3)), [open]);
```
