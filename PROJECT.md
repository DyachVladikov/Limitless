# Project: Limitless — Техническое задание

> Геймифицированная система управления жизнью: ежедневная рутина (учёба, код, спорт, питание) как хардкорная RPG с элементами визуальной новеллы. «Ты — главный герой, а твоя жизнь — это Система, которую нужно взломать и подчинить».

Этот документ — полное описание проекта: концепция, стек, архитектура, база данных, API, механики, дизайн-система и текущее состояние реализации.

---

## 1. Концепция мира

Игрок начинает с ранга **E** и прокачивает профиль до **S+** и выше, выполняя ежедневные задачи и квесты. Прогресс отражается на **шестиугольнике навыков (радар-чарте)** из конфликтующих осей:

- **Интеллект vs Сила** — хард-скиллы против физической мощи
- **Рациональность vs Эго** — холодный расчёт против амбиций и риска
- **Дисциплина vs Энергия** — рутина против ресурса и топлива

Перекос графика = дисбаланс жизни, Система это фиксирует.

**Виртуальные наставники (аниме-коучи)** — каждый со своим характером и зоной ответственности:

| Наставник | Зона | Характер |
|---|---|---|
| Сатору Годжо | Главный хаб, общий баланс | Видит всё, хвалит за стрики, язвит при перекосе статов |
| Рон Камонохаси | Академия (универ) | Помешан на деталях, дотошные чек-листы лаб |
| L | Код и алгоритмы | Прагматик, ненавидит перфекционизм ради перфекционизма |
| Сон Джин Ву | Тренировки («Врата») | Признаёт только рост, режет опыт за перетрен |
| Михаэль Кайзер | Спортивная злость (Эго) | Токсичен при пропуске тренировки |
| Сома Юкихира | Питание («Топливо») | БЖУ как визуальные колбы, пресеты еды |
| Аянокоджи Киётака | Стратегия (Рациональность) | Долгосрочное планирование, минимизация рисков |
| Юичи Катагири | Риск (Эго) | Провоцирует на агрессивные и манипулятивные решения |

**Кросс-модульность (задумано):** модули влияют друг на друга — пустая шкала энергии режет бафф интеллекта, сорванный стрик меняет поведение Годжо на главной.

**Страницы:**

- `/` — Dashboard, главный хаб (куратор Годжо): профиль, радар, стрик, задачи и квесты дня
- `/do-it` — Физподготовка (Джин Ву, Кайзер, Сома)
- `/rationality` — Ментальная прокачка (Аянокоджи, Юичи): тёмные тона, текстовые симуляции-кейсы
- `/work` — Работа и проекты

## 2. Стек

**Монорепозиторий**, две папки: `client/` и `server/`.

**Client** (`client/`, Next.js 16, App Router):
- React 19, TypeScript, SCSS (sass)
- `@tanstack/react-query` v5 — серверное состояние (запросы к API)
- `@reduxjs/toolkit` + `react-redux` — клиентское состояние (профиль юзера)
- `axios` — HTTP-клиент (`client/src/shared/api/axios.ts`, baseURL `http://localhost:3001/api/`)
- `framer-motion`, `swiper`, `react-icons`, `classnames`, `@a1rth/css-normalize`
- Линтер: `oxlint`

**Server** (`server/`, Next.js 16 API Routes, порт 3001):
- Только route handlers (`app/api/**/route.ts`), без UI
- `@supabase/supabase-js` — работа с БД через anon key
- Авторизации нет (проект соло), CORS открыт для клиента
- Запуск: `npx next dev -p 3001`

**БД:** Supabase (PostgreSQL). Миграции лежат в `server/supabase/migrations/*.sql`, применяются вручную через SQL Editor. Полная документация по всем таблицам и полям — `server/supabase/DATABASE.md`.

## 3. Архитектура клиента (FSD)

Feature-Sliced Design, слои снизу вверх (импортировать можно только вниз):

```
app/         (Next.js роутинг: app/page.tsx и т.д. — тонкие обёртки над views)
src/
  app/       провайдеры (StoreProvider, QueryProvider), store, глобальные стили
  views/     страницы: DashboardPage, DoItPage, RationalityPage, WorkPage
  widgets/   SkillsSection (профиль + радар + ранг), TaskAndQuests, Header, Footer
  features/  DailyTask (чекбокс выполнения задачи)
  entities/  user, dailyTasks, quests, stats — типы + API-хуки (useUser, useTodayTasks...)
  shared/    UI-кит (Button, Badge, CheckBox, Logo, RankBadge, MainLayout),
             api/axios, config/routes, lib (getCategoryColor, formatCamelCase)
```

**Конвенции:**
- Компонент = папка: `ComponentName.tsx` + `ComponentName.scss` + `index.ts`
- Алиас `@` → `client/src/`, относительные импорты `../../` запрещены
- Каждый слайс наружу торчит только через `index.ts` (публичный API)
- Хуки называются с `use`-префикса
- Комментарии в коде запрещены (исключение — подписи цветов в variables.scss)

**Паттерн данных:** компонент берёт данные из react-query хука слайса (`useUser()`, `useTodayTasks()`), мутации инвалидируют `queryKey` (`["user"]`, `["todayTasks"]`, `["quests"]`). Redux хранит снимок профиля для компонентов вне react-query.

## 4. База данных (кратко, детали в server/supabase/DATABASE.md)

**Активные таблицы:**

- `profiles` — профиль (1 строка): ник, ранг, уровень, exp, 6 статов радара, стрик
- `tasks` — пул из 18 задач: название, описание, иконка lucide, exp, категория, `days_of_week` (1=Пн…7=Вс, NULL = рандомный пул), `is_priority`
- `daily_tasks` — какие 5 задач выпали на день + флаг выполнения
- `quests` — пул из 59 квестов: название, описание, иконка, exp, `target_count`
- `user_quest_progress` — прогресс по квестам (`progress` / `is_completed`)
- `focus_sessions` — записи фокус-времени в минутах

**Легаси (не используются сервером, кандидаты на удаление):** `quest_templates`, `quest_completions`, `daily_logs` (БЖУ), `academy_courses`, `academy_labs`, `pet_projects`, `rationality_books`, `mental_laws`, `coach_dialogues`.

RLS включён везде, политики `allow_all` (соло-проект).

## 5. API (все эндпоинты, baseURL `http://localhost:8080/api/`)

| Метод и путь | Что делает | Тело/ответ |
|---|---|---|
| `GET /user` | Профиль (маппинг в camelCase, exp в % уровня) | `{ id, name, rank, stats, level, streak, ... }` |
| `PATCH /user` | Обновить поля профиля | частичный объект |
| `GET /tasks/today` | 5 задач на сегодня (ролл при первом запросе за день) | `[{ id, title, description, icon, exp, category, isCompleted }]` |
| `PATCH /tasks/today/:id` | Чек/анчек задачи | `{ isCompleted: boolean }` |
| `GET /quests` | Все 59 квестов с прогрессом | `[{ id, title, description, icon, exp, targetCount, progress, isCompleted }]` |
| `GET /quests?limit=3` | Топ-3 квеста по близости к завершению | то же, 3 штуки |
| `PATCH /quests/:id/progress` | Двинуть прогресс квеста | `{ amount?: number }`, дефолт 1 |
| `GET /stats/summary` | 4 цифры виджета: задачи/квесты за месяц, фокус за неделю, очки за месяц | `{ tasksCompleted, questsCompleted, focusMinutes, pointsEarned }` |
| `POST /focus` | Записать фокус-сессию | `{ minutes: number }` |

## 6. Игровые механики (реализовано)

**Опыт и уровни:** `expToNextLevel = current_level * 100`. При переполнении — цикл level up с переносом остатка. `total_exp` копится всегда.

**Ранги:** `E → D → C → B → A → S → S+ → SS → SSS`. У каждого свой визуал (компонент `RankBadge`): E — приглушённая «пыль», дальше рамка → свечение → неон → анимированный градиент; SS/SSS — ауры-пламя вокруг буквы.

**Ролл задач на день** (`GET /tasks/today`): из `tasks` берутся задачи, чей `days_of_week` содержит сегодня, плюс рандомный пул (`days_of_week = NULL`); задачи с `is_priority = true` (силовая, волейбол) гарантированы в свой день; итог режется до 5 и фиксируется в `daily_tasks`.

**Статы за задачи:** выполнение задачи даёт её exp и +1 к стате по категории: study→интеллект, sport→сила, health→энергия, work→дисциплина, rationality→рациональность. Снятие галочки забирает exp обратно (уровень не откатывается).

**Квесты:** `PATCH /quests/:id/progress` инкрементит прогресс; при достижении `target_count` — автокомплит, начисление exp квеста и +1 к Эго.

**Стрик:** растёт при активности в consecutive дни (`last_active_date`), сбрасывается при пропуске дня.

**Цвета категорий задач** (для бейджей): study `#8B5CF6`, sport `#3A86FF`, health `#FB923C`, work `#06D6A0`, rationality `#E63946`.

## 7. Дизайн-система

Неоновый тёмный стиль. У каждой страницы своя палитра (CSS-переменные в `client/src/app/styles/variables.scss`), цвет акцента страницы = цвет свечения хедера:

| Страница | Палитра | Акцент | Фоны |
|---|---|---|---|
| `/` Dashboard | «Neon Space» | фиолет `#8B5CF6` + синий `#4F7CFF` | космос `#04040F → #141433` |
| `/rationality` | «Dark Ruby» | рубин `#E63946` + сталь `#8D9299` | пепел `#0A090A → #221A1C` |
| `/do-it` Sport | «Jin Woo Blue» | синий `#3A86FF` + циан `#7DD3FC` | ночь `#030710 → #122144` |
| `/work` | «Neon Emerald» | изумруд `#06D6A0` | хвоя `#030A08 → #112C23` |

У каждой палитры одинаковая структура: 4 фона, 4 оттенка акцента, текст (glow/muted), 4 свечения, 3 градиента, обводки, стекло. Базовые переменные (белый/чёрный/серые/ошибка/обводки/радиусы/шрифты) — общие на всех.

Шрифты: `Plus Jakarta Sans` (основной), `JetBrains Mono` (цифры/код).

## 8. Реализовано vs задумано

**Уже работает:**
- Профиль с рангом, уровнем, 6 статами, стриком; радар-чарт шестиугольник; анимированный `RankBadge`
- Ежедневный ролл 5 задач с расписанием и приоритетами, чек/анчек с начислением exp
- 59 квестов с прогрессом и автокомплитом, виджет «ближайшие к завершению»
- Виджет сводной статистики (задачи/квесты/фокус/очки), запись фокус-сессий
- Перекраска хедера под страницу, 4 палитры страниц

**Задумано, но не реализовано:**
- Живые коучи на страницах: реплики по событиям, штрафы за перетрен/дисбаланс, токсичность Кайзера (есть таблица `coach_dialogues` и роут `/api/coaches` — задел)
- Кросс-модульные баффы/дебаффы (еда → интеллект и т.п.)
- Блок питания Сомы: колбы БЖУ, пресеты еды (задел — `daily_logs`)
- Чек-листы лаб Рона (задел — `academy_labs` с чек-полями)
- Текстовые симуляции-кейсы Аянокоджи/Юичи с выбором «безопасность vs риск»
- Отдельная страница всех квестов (API уже умеет — `GET /quests` без limit)
- Удаление легаси-таблиц из БД
